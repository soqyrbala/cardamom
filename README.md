# Cardamom Cafe

Multi-page responsive website for a small cafe and bakery (Midterm project).

## Pages
Home, Menu (table), About, Gallery (CSS Grid), Contact (form).

## Features
- Semantic HTML5: header, nav, main, section, article, aside, footer
- Table (menu prices) and form (contact)
- Flexbox (hero, navbar) and Grid (gallery, about page)
- Positioning: sticky header, absolute badge on hero
- Media queries: 992px (tablet) and 576px (mobile)
- Bootstrap 5 grid, navbar, utilities, buttons
